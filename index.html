About

MARK RYAN HILARIO

Web Developer | IS Instructor

I’m a recent Computer Science graduate who did not fall in love with programming right away. I struggled early on, then slowly built real skills through curiosity-driven mini projects. That curiosity turned into passion, and I grew from barely understanding HTML to building full systems and doing commissions.

I enjoy creating things from scratch, with a current focus on backend development while still caring a lot about clean structure and design using HTML, CSS, and Figma. I work deliberately and prefer doing things properly, even if it takes longer, because I want to understand the why, not just make something work.

When solving problems, I focus on finding the root cause first, breaking issues into smaller parts, reading documentation, and testing in small steps. If I need help, I ask or research, but I avoid copy-pasting so I can apply what I learn confidently in future projects
